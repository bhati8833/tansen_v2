# Tansen Sangeet Mahavidyalaya — Course Page Design System

## Purpose

All individual course pages must use one unified design system.

Only the following should change from course to course:

* Course name
* Category
* Sub-category
* Course description
* Course-specific learning modules
* Course-specific images
* Course-specific icons
* Course-specific FAQs
* SEO title
* SEO description
* URL
* Course-specific metadata

The overall layout, spacing, typography, buttons, cards, CTA sections, FAQ design, and visual hierarchy should remain consistent.

---

# URL Structure

Use category and sub-category based URLs.

### Example

`/courses/music/classical-vocal-singing/`

### Fine Arts

`/courses/creative-arts/fine-arts/`

### Suggested Structure

`/courses/{category}/{course-slug}/`

Examples:

* `/courses/music/classical-vocal-singing/`
* `/courses/instruments/guitar/`
* `/courses/instruments/tabla/`
* `/courses/instruments/drums/`
* `/courses/instruments/keyboard-piano/`
* `/courses/dance/kathak/`
* `/courses/dance/western-dance/`
* `/courses/creative-arts/fine-arts/`

Do not use course-specific random URL structures.

# Page Layout

Every course page should follow this exact order:

1. Breadcrumb
2. Hero Section
3. Course Introduction
4. What is [Course]?
5. What Will You Learn?
6. Course Highlights
7. Who Can Join?
8. Why Choose Tansen?
9. Learning Journey
10. Course Schedule
11. Certification / Learning Opportunities where applicable
12. Gallery / Course Images
13. FAQs
14. Final CTA
15. Contact / Footer

---

# 1. Breadcrumb

Example:

Home → Courses → Music & Vocal → Classical Vocal Singing

For Fine Arts:

Home → Courses → Creative Arts → Fine Arts

Breadcrumb should be clickable.

Use `BreadcrumbList` structured data.

---

# 2. Hero Section

Hero should immediately communicate:

* Course name
* Location
* Short description
* Primary CTA
* Secondary CTA
* Course-related visual

### Layout

Desktop:

Left:

* Small category label
* H1
* 2–3 line description
* CTA buttons

Right:

* Course image / visual

Mobile:

* Text first
* Image below
* CTA buttons below description

### H1 Format

`[Course Name] Classes in Gurugram`

Example:

`Classical Vocal Singing Classes in Gurugram`

`Fine Arts Classes in Gurugram`

# CTA Buttons

Primary:

`Book Free Demo`

Secondary:

`Enquire Now`

Primary CTA should be visually stronger.

CTA should appear:

* Hero
* Mid-page
* Final CTA

---

# 3. Course Introduction

Use a clean two-column section.

Left:
Course-related image

Right:
Short introduction

Do not make this section excessively long.

Use a maximum of approximately 100–150 words.

---

# 4. What is [Course]?

Use a clean text section.

Optional visual element:

* Course icon
* Small illustration
* Supporting image

This section should explain the course in simple language.

---

# 5. What Will You Learn?

This is one of the most important sections.

Use a responsive card grid.

Desktop:
3 cards per row

Tablet:
2 cards per row

Mobile:
1 card per row

Each card contains:

* Icon
* Skill/topic title
* 2–4 line description

Example:

### Swar & Alankar

Short description.

### Raga

Short description.

### Taal & Laya

Short description.

For Fine Arts:

### Drawing & Sketching

Short description.

### Colour Theory

Short description.

### Painting

Short description.

---

# 6. Course Highlights

Use compact feature cards or a checklist.

Example:

* Structured Learning
* Regular Practice
* Skill Development
* Creative Expression
* Performance Opportunities
* Free Demo Class

Do not use the same course-specific learning points twice.

The "What Will You Learn?" section explains the curriculum.

"Course Highlights" explains the benefits/features.

---

# 7. Who Can Join?

Use four consistent cards:

### Kids

### Beginners

### Experienced Learners

### Adults

If a course has a specific audience, content can be modified but the visual system should remain consistent.

---

# 8. Why Choose Tansen?

Use 4–6 feature cards.

Recommended universal features:

* Structured Learning
* Student-Focused Guidance
* Regular Practice
* Experienced Guidance
* Performance Opportunities
* Free Demo Class

Only use claims that are supported by the institute's actual information.

---

# 9. Learning Journey

Use a horizontal process on desktop and vertical process on mobile.

### Step 1

Foundation

↓

### Step 2

Practice

↓

### Step 3

Skill Development

↓

### Step 4

Creative Expression

↓

### Step 5

Performance

For Fine Arts this can be:

`Explore → Learn → Practice → Create → Express`

The labels may change according to the course, but the component design remains identical.

---

# 10. Course Schedule

Use a compact information card.

Display:

* Minimum weekly learning: 2 hours
* Class frequency: Regular
* Batch timings: Based on availability
* Age group: 3+ to adults

Add CTA:

`Enquire About Batches`

Do not publish exact fees unless the institute has finalized them.

---

# 11. Certification

Only display this section where relevant.

If included:

* Use a dedicated visual section.
* Clearly distinguish affiliations from certifications.
* Do not claim that every course automatically provides certification.

Use actual approved/verified affiliations only.

---

# 12. Gallery

Use real institute/course photographs whenever possible.

Recommended:

* 4–8 images
* Classroom learning
* Student practice
* Performance
* Instructor interaction
* Course-specific activities

Avoid excessive stock photography.

Gallery should be responsive.

Desktop:
4-column or masonry layout

Mobile:
2-column layout

---

# 13. FAQ Section

Use accordion design.

Each course page should have approximately 5–8 relevant FAQs.

Questions should be course-specific.

Universal examples:

* Is this course suitable for beginners?
* What age can students join?
* Is a demo class available?
* How many hours per week are classes?
* What will students learn?
* Can adults join?

Do not repeat the entire website FAQ page.

Add:

`View All FAQs`

if a dedicated FAQ page exists.

---

# 14. Final CTA

Every course page must end with a strong conversion section.

### Heading

`Ready to Begin Your [Course] Journey?`

### Supporting text

`Book a free demo class and discover the right learning path for you.`

Buttons:

`Book Free Demo`

`Call Now`

# Visual Design System

## Overall Style

The design should communicate:

* Premium
* Educational
* Artistic
* Trustworthy
* Modern
* Warm
* Professional

Avoid making the website look like a generic children's activity website.

---

# Typography

Use one consistent font system across all course pages.

Recommended:

### Headings

Modern, elegant, bold typeface.

### Body

Highly readable sans-serif.

Maintain consistent:

* H1 size
* H2 size
* H3 size
* Body size
* Line height
* Letter spacing

Do not change typography for individual courses.

---

# Colour System

Use the website's global brand colours.

Do not create a completely different colour palette for each course.

Course pages may use subtle course-specific visual accents, but the primary brand identity must remain consistent.

---

# Cards

All course cards should have:

* Consistent border radius
* Consistent padding
* Subtle border/shadow
* Consistent icon placement
* Consistent hover animation

Avoid excessive animations.

---

# Buttons

All CTA buttons must use the same global button component.

Primary:

`Book Free Demo`

Secondary:

`Enquire Now`

Use consistent:

* Height
* Border radius
* Font
* Padding
* Hover state

# SEO Structure

Every course page must have:

* Unique SEO title
* Unique meta description
* One H1
* Logical H2/H3 hierarchy
* SEO-friendly URL
* Breadcrumbs
* Internal links
* Optimized image alt text
* Course-specific content
* FAQ section

Avoid keyword stuffing.

---

# Structured Data / Schema

Use only schemas that accurately describe visible page content.

## Recommended

### Course Schema

For dedicated course pages.

Include appropriate:

* Course name
* Description
* Provider
* Course URL

### BreadcrumbList

For:

Home → Courses → Category → Course

### Organization / LocalBusiness

Use appropriate organization/location markup at the site level where applicable.

### FAQPage

Use only for FAQs that are actually visible on the page.

Do not create hidden FAQ content solely for schema.

### Review / AggregateRating

Only use genuine review/rating information that meets the applicable structured-data requirements.

Never create fake ratings.

* Learning journey

* CTA

* Final CTA
* Footer

---

# Course Data Structure

Recommended approach:

Each course should have its own content object/data rather than creating completely separate page designs.

Example:

```text
course:
  name
  category
  subcategory
  slug
  description
  heroImage
  learningModules
  highlights
  audience
  learningJourney
  schedule
  faqs
  seoTitle
  metaDescription
```

Then the same course-page template renders different courses.

This ensures design consistency and makes future course additions easier.

---

# Final Design Principle

**One Course Page Template + Different Course Content**

Do not design every course page separately.

The user should immediately recognize that Classical Vocal Singing, Fine Arts, Guitar, Tabla, Drums, Keyboard, Kathak, and Western Dance belong to the same academy and the same website system.

Only the course content and visual assets should change.
